# 금융 자료 수집 · 정리 앱 (finance-data-collector)

법인 · 개인 **카드 사용내역**, **은행 계좌 거래내역**, **홈택스 자료**(전자세금계산서 · 현금영수증 · 사업용카드)를
AI 브라우저 **Aside** 로 내려받고, 이 앱이 자동으로 읽어 **항목별 · 월별로 정리**합니다.
**회사 ERP** 자료도 항목별로 모을 수 있습니다. 이 기능과 ERP 접속 안내는 **앱 인증키로 로그인해야** 보입니다.

**자주 쓰는 기관 바로가기**: IBK기업은행 계좌 · 하나은행 계좌 · BC카드 · 기업BC카드(IBK) — 누르면 접속 주소까지 들어간 작업지시가 만들어집니다.

| 화면 | 하는 일 |
|---|---|
| ① 수집 지시 (Aside) | 홈택스 · 은행 · 카드사별로 Aside 에 붙여넣을 작업지시를 만들어 줍니다(기간 · 저장 폴더 포함) |
| ② 자료 정리 | 수집함의 xlsx · csv · 은행 엑셀을 읽어 종류를 알아보고 하나로 합칩니다. 중복 거래는 한 번만. 행마다 항목을 바꿀 수 있고 CSV 로 저장 |
| ③ 항목별 집계 | 나간 돈 · 들어온 돈 · 세금계산서를 항목 × 월 표로. 카드대금처럼 두 번 세게 되는 돈은 뺍니다 |
| ④ ERP 자료 🔒 | 인증키로 로그인하면 ERP 접속 주소 · 메뉴 안내가 열립니다. 화면을 고르면 Aside 작업지시를 만들고, 받은 파일을 화면별로 보여 줍니다 |

- **모든 자료는 이 PC 안에서만 읽습니다.** 인터넷으로 보내지 않습니다. 외부 패키지도 없습니다.
- 처음 써 볼 때는 `samples` 폴더의 **가상 예시 자료**를 `수집함` 에 복사해 보세요(실제 회사 · 계좌와 무관합니다).

## 설치

준비물은 **Node.js 18 이상**(https://nodejs.org) 과 **Aside**(AI 브라우저, 공식 사이트에서 설치) 입니다.

1. **카카오톡으로 zip 을 받았다면** PC 에 저장해 압축을 풉니다. GitHub 에서는 **Releases** 의 zip 을 받습니다.
2. `실행.bat` 을 더블클릭합니다(macOS 는 `sh start.sh`). 처음 한 번 `npm install` 을 하고 브라우저가 열립니다.
3. 직접 하려면 `npm install` 후 `npm start`, 그리고 **http://localhost:5198** 을 엽니다.

## 쓰는 순서

1. **① 수집 지시**에서 가져올 자료와 기간을 고르고 **복사**합니다.
2. **Aside** 채팅창에 붙여넣습니다. 로그인 화면에서 Aside 가 멈추면 **공동인증서 · OTP 로그인은 직접** 하고 "계속" 이라고 말합니다.
3. Aside 가 엑셀을 `수집함` 폴더에 내려받으면 **② 자료 정리 → 다시 읽기**를 누릅니다.
4. 항목이 틀린 행은 고치고, **③ 항목별 집계**에서 월별 합계를 보거나 CSV 로 저장합니다.

## 회사 ERP 자료와 인증키

**④ ERP 자료**는 배포자에게 받은 **앱 인증키**(`SMK-XXXX-XXXX-XXXX-XXXX`)로 로그인해야 열립니다.
- **ERP 접속 주소 · 메뉴 · 작업지시 안내는 로그인해야 보입니다.** 이 저장소와 zip 에는 암호화된 형태(`config/erp-guide.enc`)로만 들어 있습니다.
- 인증키는 ERP 의 회사아이디 · 비밀번호와 다릅니다. ERP 로그인은 Aside 화면에서 본인이 직접 합니다.
- 장부를 바꾸는 메뉴는 고를 수 없게 했고, Aside 작업지시에도 열지 말라고 적혀 있습니다(자세한 내용은 로그인 후 안내).
- 엑셀 버튼 없이 인쇄만 있는 화면은 Aside 가 화면의 표를 CSV 로 옮겨 저장합니다. 머리줄이 두 줄인 표도 읽습니다.
- 키를 5번 틀리면 1분 동안 막힙니다. 한 번 열면 8시간(또는 브라우저 탭을 닫을 때까지) 유지됩니다.

**배포하는 사람이 키와 안내를 관리하는 방법** (자세한 설명은 `tools/make-key.mjs` 맨 위)
```bash
node tools/make-key.mjs 발급 "홍길동(가나회계)" --admin-key-file <관리자키 파일>
node tools/make-key.mjs 목록
node tools/make-key.mjs 폐기 "홍길동(가나회계)"
node tools/make-key.mjs 안내풀기 --admin-key-file <관리자키 파일> --guide <안내.json>
node tools/make-key.mjs 안내잠그기 --admin-key-file <관리자키 파일> --guide <안내.json>
```
- 키 원문은 발급할 때 **한 번만** 화면에 나옵니다. `config/erp-keys.json` 에는 해시와 감싼 열쇠만 저장됩니다.
- 관리자 키 파일과 안내 원문(.json)은 **저장소 밖에** 두세요.
- 발급 · 폐기 · 안내 수정 후에는 새 버전을 배포해야 받는 사람의 앱에 반영됩니다. 폐기한 사람이 예전 판을 갖고 있으면 그 판의 안내는 회수할 수 없습니다.
- **인증키는 "키를 받은 사람만 이 기능과 안내를 쓰게" 하는 장치입니다.** ERP 자료 자체의 보안은 ERP 계정(회사아이디 · 비밀번호)과 권한 설정으로 지키세요.

## 안전하게 쓰기

- Aside 작업지시에는 **"조회 · 내려받기만, 이체 · 결제 · 설정 변경 · 전표 수정 금지"** 가 들어 있습니다. 그래도 Aside 가 무엇을 누르는지 지켜보세요.
- 은행 · 카드 비밀번호나 인증서 암호를 Aside 채팅에 적지 마세요.
- `수집함` 의 파일에는 계좌 · 카드 정보가 들어 있습니다. 다 쓰면 지우거나 안전한 곳에 보관하세요(`.gitignore` 로 GitHub 에는 올라가지 않습니다).
- 이 앱의 분류는 거래처 이름에 따른 자동 분류입니다. 장부 · 세무 신고에 쓰기 전에 사람이 확인하세요.

## 파일이 안 읽힐 때

| 증상 | 조치 |
|---|---|
| "예전 엑셀(.xls) 형식입니다" | 엑셀에서 열어 **다른 이름으로 저장 → Excel 통합 문서(.xlsx)** |
| "자료 종류를 알아보지 못했습니다" | 파일 이름에 "카드" · "거래내역" · "세금계산서_매출" · "현금영수증" 같은 말을 넣고 다시 읽기 |
| 거래처 · 금액 칸이 비어 나옴 | 은행 · 카드사마다 칸 이름이 다릅니다. `lib/parse.mjs` 의 칸 이름 목록에 추가하세요 |
| 항목 분류가 맞지 않음 | `public/rules.js` 의 `CATEGORY_RULES` 에 거래처 낱말을 추가하세요 |
